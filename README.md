## 🎯 Project Overview

Vision Mouse is a **comprehensive, production-ready gaze estimation system** that enables hands-free computer interaction through advanced eye tracking technology. Built with Angular 19 and powered by Google's MediaPipe, this system delivers real-time, accurate gaze prediction with intelligent optimization and comprehensive analytics.

## 🛠️ Installation & Setup

### Prerequisites
- **Node.js**: Version 18.19+ 
- **npm**: Version 9.0+
- **Modern Browser**: Chrome, Firefox, or Edge with WebRTC support
- **Webcam**: HD camera with good lighting conditions

### Quick Start

1. **Clone the Repository**
   ```bash
   git clone https://github.com/PatcharaphonTiw/Vision_Mouse.git
   cd Vision_Mouse
   ```

2. **Install Dependencies**
   ```bash
   npm install
   ```

3. **Start Development Server**
   ```bash
   npm start
   ```

4. **Open Application**
   Navigate to `http://localhost:4200` in your browser

5. **Grant Camera Permissions**
   Allow camera access when prompted by the browser
